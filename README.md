# Corvelox
<img src="img/logo.png" width=60%>

Android向けの単語暗記アプリケーション。  
カラスのように頭がよく、素早く暗記できることを願って命名

昨今のAIコーディングの感じを掴むため、AIの手綱を握りつつ時短の道を探るため、今まで欲しかった単語帳アプリを作成。  

コーディング面ではほどほど、
データ作成においては多大なる貢献をAIから受けています。
